PromoGrind Calc API

Use PromoGrind calculators in your own tools and content. The browser calculators are available now; a public calculator API is planned.

API availability: public API access is not currently offered. Contact us to discuss an integration, or use the calculator embeds.

Planned calculations: the examples below describe proposed calculator inputs and outputs. Connection details, access requirements and usage limits will be provided when API access becomes available.

POST
/bonus-bet

Convert bonus bets into modeled-cash outputs.

POST
/arb-2way

Calculate arbitrage stake sizing and modeled outcomes.

POST
/ev

Expected-value calculation against a supplied fair probability.

POST
/profit-boost

Boosted-odds value and optimal hedge sizing.

POST
/no-vig

Fair-odds and implied probability output.

POST
/kelly

Kelly fraction and bankroll sizing guidance.
