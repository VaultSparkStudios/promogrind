# Project Brief

## Identity

- Name: PromoGrind
- Slug: promogrind
- Type: App / product — web-based sportsbook promo conversion tool
- Status: Active — v3 complete, pre-launch
- Owner: VaultSpark Studios

## Why this exists

- Problem or opportunity: Sportsbook promotions (bonus bets, deposit matches, profit boosts, referral offers) represent real money that most bettors leave on the table because the math is opaque. Tools that do this math exist but cost $99–$199/month. PromoGrind makes it free.
- Audience: US sports bettors (21+) in states with legal sports betting; particularly promo-hunters, matched bettors, and +EV players who want to extract guaranteed profit from sportsbook offers.
- Studio importance: Standalone monetizable product. Generates affiliate revenue through embedded sportsbook links and SEO traffic. Demonstrates VaultSpark's capability to ship polished, useful tools beyond games.

## Success

- What success looks like: Tool is live, loads fast, all 11 calculators produce correct results, affiliate links are set, site ranks for target keywords, users share it organically.
- What this project is not: A gambling app. Not a sportsbook. Not financial advice. Not a subscription product (free tier is the core product). Not a platform for illegal activity.

## Scope

- In scope: Bonus bet conversion calculator, first-bet hedge calculator, arbitrage calculator, +EV calculator, profit boost calculator, referral bonus tracker, P/L ledger, sportsbook tracker, knowledge base for beginners, affiliate link integration, SEO meta setup.
- Out of scope (v1): Live odds API, paid subscription tier, user accounts, server-side logic, real-time scanning. (Planned for v2 — see RELEASE_PLAN.md)
