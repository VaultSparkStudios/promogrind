# Security Reporting

## Reporting a vulnerability

If you discover a security vulnerability in **PromoGrind**, please report it
privately. **Do not open a public issue for security problems.**

- **Email:** [contact@promogrind.bet](mailto:contact@promogrind.bet) (subject: `SECURITY — PromoGrind`)
- **GitHub private vulnerability reporting:** if enabled on this repository
  (Security → "Report a vulnerability"), prefer that channel.

Please include what you found, steps to reproduce, the affected version or commit,
and the potential impact. Remove passwords, access tokens, and personal information
from examples and screenshots.

## Scope

Reports may concern this repository's code, configuration, or deployed PromoGrind
service. If a dependency vulnerability affects PromoGrind, include that impact;
the dependency's maintainer may also need a private report.

## Disclosure

Please allow time for private investigation before publishing vulnerability
details. Include whether you would like to be credited if the issue is disclosed.
